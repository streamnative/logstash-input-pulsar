=== Pulsar input plugin

include::{include_path}/plugin_header.asciidoc[]

==== Description

Read events from an https://pulsar.apache.org/[Apache Pulsar] cluster.
This plugin uses Pulsar Client 4.0.9 to consume messages from one or more Pulsar topics
and feed them into the Logstash pipeline.

Messages can be decoded as plain text (placed in the `message` field) or as JSON
(mapped directly into event fields).

[id="plugins-{type}s-{plugin}-serviceUrl"]
===== `serviceUrl`

  * Value type is <<string,string>>
  * Default value is `"pulsar://localhost:6650"`

The Pulsar service URL. Use `pulsar://` for plaintext connections or `pulsar+ssl://` for TLS.

[id="plugins-{type}s-{plugin}-topics"]
===== `topics`

  * Value type is <<array,array>>
  * There is no default value for this setting.
  * Required

A list of Pulsar topic names to subscribe to (e.g., `["persistent://public/default/my-topic"]`).

[id="plugins-{type}s-{plugin}-subscriptionName"]
===== `subscriptionName`

  * Value type is <<string,string>>
  * There is no default value for this setting.
  * Required

The name of the Pulsar subscription.

[id="plugins-{type}s-{plugin}-consumerName"]
===== `consumerName`

  * Value type is <<string,string>>
  * There is no default value for this setting.

An optional name for the Pulsar consumer instance.

[id="plugins-{type}s-{plugin}-subscriptionType"]
===== `subscriptionType`

  * Value type is <<string,string>>
  * Default value is `"Shared"`

The Pulsar subscription type. One of: `Exclusive`, `Failover`, `Shared`, `Key_Shared`.

[id="plugins-{type}s-{plugin}-subscriptionInitialPosition"]
===== `subscriptionInitialPosition`

  * Value type is <<string,string>>
  * Default value is `"Latest"`

Where to start reading when no existing subscription cursor is found.
One of: `Latest`, `Earliest`.

[id="plugins-{type}s-{plugin}-codec"]
===== `codec`

  * Value type is <<string,string>>
  * Default value is `"plain"`

How to decode messages. `plain` places the message body in the `message` field.
`json` parses the message body as JSON and maps fields into the Logstash event
(falls back to `plain` on parse errors).

[id="plugins-{type}s-{plugin}-enable_tls"]
===== `enable_tls`

  * Value type is <<boolean,boolean>>
  * Default value is `false`

Set to `true` to enable TLS authentication using a JKS keystore.

[id="plugins-{type}s-{plugin}-tls_trust_store_path"]
===== `tls_trust_store_path`

  * Value type is <<string,string>>
  * Default value is `""`

Path to the JKS trust store file. Required when `enable_tls` is `true`.

[id="plugins-{type}s-{plugin}-tls_trust_store_password"]
===== `tls_trust_store_password`

  * Value type is <<string,string>>
  * Default value is `""`

Password for the JKS trust store.

[id="plugins-{type}s-{plugin}-enable_tls_hostname_verification"]
===== `enable_tls_hostname_verification`

  * Value type is <<boolean,boolean>>
  * Default value is `true`

Whether to verify the hostname in the TLS certificate.

[id="plugins-{type}s-{plugin}-allow_tls_insecure_connection"]
===== `allow_tls_insecure_connection`

  * Value type is <<boolean,boolean>>
  * Default value is `false`

Allow the Pulsar client to connect to brokers with untrusted TLS certificates.

[id="plugins-{type}s-{plugin}-protocols"]
===== `protocols`

  * Value type is <<array,array>>
  * Default value is `["TLSv1.2"]`

List of TLS protocol versions to allow.

[id="plugins-{type}s-{plugin}-ciphers"]
===== `ciphers`

  * Value type is <<array,array>>
  * Default value includes `TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256`,
    `TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384`, `TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256`,
    `TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384`

List of TLS cipher suites to allow.

[id="plugins-{type}s-{plugin}-auth_plugin_class_name"]
===== `auth_plugin_class_name`

  * Value type is <<string,string>>
  * Default value is `""`

The fully qualified class name of the Pulsar authentication plugin.
For example, `org.apache.pulsar.client.impl.auth.AuthenticationToken`.
Used when `enable_tls` is `false`.

[id="plugins-{type}s-{plugin}-auth_params"]
===== `auth_params`

  * Value type is <<string,string>>
  * Default value is `""`

Authentication parameters as a string (e.g., `token:<your-token>`).
Used together with `auth_plugin_class_name`.
